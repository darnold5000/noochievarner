# Noochie Varner Baseball Academy

Sales demo for the academy site. Booking and payments stay on the current EZFacility account. Destinations live in `src/config/booking.ts`.

```bash
npm install
npm run dev
```

Search engines are blocked (`noindex` plus `robots.txt`). Flip that only when the owner asks for the site to be indexed, then redeploy.

This project does not share environment variables, a database, or a deployment with any other client site.
